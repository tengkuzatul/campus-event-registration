# User Stories

Format: As a lecturer, I want to evaluate student performance, so that everyone know their weakness.
1. As a ..., I want ..., so that ...
2. As a ..., I want ..., so that ...
3. As a ..., I want ..., so that ...

1. As a lecturer, I want to see each student's marks grouped by topic, so that I can identify who needs extra help. (FR1)

   Acceptance criteria:
   - Selecting a student shows their marks for every topic in the course.
   - Any topic with a mark below 50% is marked as weak.
   - The results appear within 3 seconds.

2. As a student, I want to see my weak topics after each assessment, so that I know what to revise first. (FR2)

   Acceptance criteria:
   - I can see my own marks only, not other students' marks.
   - My weak topics are listed from the lowest mark to the highest.
   - Each weak topic shows the topic name and my mark.
